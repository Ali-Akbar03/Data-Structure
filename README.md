Stack Data Structure
Stack is a linear data structure that follows LIFO (Last In First Out) Principle, the last element inserted is the first to be popped out. It means both insertion and deletion operations happen at one end only.
LIFO(Last In First Out) Principle
1.The LIFO principle means that the last element added to a stack is the first one to be removed.
2.New elements are always pushed on top.
3.Removal (pop) also happens only from the top.
4.This ensures a strict order: last in → first out.
